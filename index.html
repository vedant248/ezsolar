Design notes

Why we built it this way

Kept in English - judge/developer documentation, not user-facing screen content.
🎨 Brand
Primary blue is Tata Power's real Congress Blue (#023A8E) and the green accent is their Vida Loca Green (#3BAA1D), both pulled from official brand assets rather than approximated. Gold stays a solar-specific accent layered on top. "EZ Solar" follows Tata Power's existing consumer-product naming pattern (EZ Charge, EZ Home) instead of inventing a standalone brand, and leans on their own "brighter, greener tomorrow" positioning.
🅃 Logo
The topbar redraws the blue T-mark + "TATA POWER" wordmark shape as a close visual approximation, rather than using the official trademarked SVG asset, pending brand sign-off.
🔒 Privacy
The community leaderboard shows neighbors by name by default, but includes a one-tap anonymize toggle (Household A/B) since showing another user's exact usage is a trust decision, not just a display choice.
🔍 Research
Existing bill-credit and prepaid-recharge apps show raw kWh/₹ numbers with no context, so users can't tell if a number is good or bad. Rather than guess one explanation style, we shipped all three as a toggle (Simple / Standard / Technical).
♿ Accessibility
Older, less tech-literate renters need more than a bigger font - they need plain language and audio too. Senior-friendly mode changes text size and explanation depth together, plus a persistent high-contrast and read-aloud panel on every screen. Hindi was scoped first as the highest-reach regional language for this launch city; the toggle is built to extend to more languages without redesign.
🎯 Userbase
Community solar's real target - renters - usually share a flat with roommates on separate Tata Power accounts. No existing solar app splits one subscription's credit across multiple bills, so we built Split the Sun, with a confirmation step so credit only routes once a flatmate verifies their own account.
📉 Onboarding drop-off
Generic slide intros cause drop-off because there's no payoff. Our 2-question quiz ends with an actual, named plan recommendation before the user has to think - value shown before effort asked.
